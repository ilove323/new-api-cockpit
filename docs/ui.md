# 界面规范

四个页面使用同一套顶栏、侧边栏和基础控件，视觉规范参考 New API `v1.0.0-rc.40`
的[主题](https://github.com/QuantumNous/new-api/blob/v1.0.0-rc.40/web/src/styles/theme.css)、
[按钮](https://github.com/QuantumNous/new-api/blob/v1.0.0-rc.40/web/src/components/ui/button.tsx)
和[表格](https://github.com/QuantumNous/new-api/blob/v1.0.0-rc.40/web/src/components/ui/table.tsx)。
页面保持独立的 Jinja、CSS 和原生 JavaScript 实现，不引入官方 React 组件或构建链。

## 公共样式

| 元素 | 规范 |
|---|---|
| 主色 | 蓝色，主色值 `oklch(0.692 0.141 243.716)`；选中项使用浅蓝背景 |
| 页面与表格 | 白底、浅灰边框、灰色表头、圆角面板；金额右对齐、等宽数字 |
| 字体 | 本地 Public Sans；中文回退到系统中文无衬线字体，不依赖外部 CDN |
| 文字 | 正文、表格与常规按钮 14px；次要信息 12px；页面标题 18px |
| 控件 | 常规按钮与输入框高 32px；标题栏新增按钮高 28px |
| 图标 | Lucide；常规按钮与侧栏 16px，顶栏铃铛/设置 20px，品牌图标 24px |
| 表格 | 表头高 40px，普通数据行至少 60px；内容过长时允许增高或横向滚动 |
| 导航 | 顶栏高 48px；侧栏宽 208px，收起时只显示图标；窄屏展开覆盖内容 |

`static/ui.css` 统一颜色变量、字体、图标、按钮、表格、筛选菜单和弹窗。
各页面样式只定义业务布局，不各自维护颜色或基础控件。
`static/navigation.css` 和 `navigation.js` 管理导航尺寸与展开状态；本地存储失败不影响使用，
窄屏支持点击遮罩或按 Escape 收起导航。

字体文件与许可在 `static/fonts/`；图标文件在 `static/icons/`，静态按钮与导航共用
`static/icons.svg` 和 `partials/icons.html`。字体和图标随安装包分发，保留原始许可，见 [NOTICE](../NOTICE)。
这些资源与页面一样要求管理员认证。

## 按钮与功能位置

- **通用**：标题在左，新增、导出等页面级操作在标题栏右侧；搜索和筛选在表格上方，刷新在筛选栏右侧。
- **用户管理**：新增用户在右上；用户状态与按组选择靠近搜索；批量选择、金额和预览放在独立批量操作区。
  编辑、重置密码、启禁和删除在最后一列，以带名称和悬浮提示的紧凑图标按钮呈现。
- **令牌管理**：新增 KEY、通过 KEY 找用户在右上；用户与 KEY 的筛选在列表上方；目标分组与批量改组放在独立批量区。
  KEY 行末保留详情、编辑、额度、查看/复制、启禁和删除操作，第一列继续合并所属用户。
- **用量统计**：导出在右上；账本切换、时间查询、指标、排名和明细各自成区。
  用户/模型/令牌/分组筛选和显示列位于明细表上方，不影响其他区域；铃铛和余额设置位于顶栏右侧。
- **操作记录**：类型筛选与刷新在表格上方，详情在行末，翻页在表格底部。
  定时额度设置仍从用户管理的顶栏齿轮进入，执行记录统一在操作记录页。

图标按钮保留 `aria-label`、键盘焦点和名称提示，危险操作仍有确认步骤。
列表金额只显示两位小数；悬浮公式、实际计算、接口和 Excel 的精度与业务规则不由样式改变。
