# 聊天开发说明

本文描述当前实现，不是实施计划。使用与配置见[聊天手册](chat.md)，接口字段见[API 参考](api.md#ai-助手需显式启用)和站点的交互式 API 文档，验证入口见[贡献指南](../CONTRIBUTING.md#ai-助手离线回归)。

## 模块与依赖

业务代码位于 `src/new_api_cockpit/features/chat/`，由宿主通过 `composition.py` 注入已验证身份和本人 KEY 访问能力。

| 模块 | 职责 |
|---|---|
| `http.py`、`openapi.py`、`schemas.py` | HTTP 边界、接口文档、字段校验 |
| `service.py`、`runner.py` | 接受运行、幂等、预算、停止和有界工具循环 |
| `storage.py`、`fs.py`、`event_index.py`、`recovery.py` | 本地文件、提交高水位、恢复与派生索引 |
| `protocols.py`、`transport.py` | 三种模型协议、SSE、原生连续状态与网络截止 |
| `attachments.py`、`workspace.py`、`tools.py`、`document_worker.py`、`media.py`、`outputs.py`、`output_worker.py` | 附件、工作区工具、文档/图片读取及真实二进制输出 |
| `web_tools.py` | 受控公网搜索、读取和文本下载 |
| `user_context.py`、`skills.py`、`auto_memory.py` | 个人设置、Skills、自动记忆及撤销 |
| `context.py`、`working_context.py` | 运行快照、历史投影、压缩与检查点 |
| `config.py` | 资源限制和运维配置 |

聊天、生图是独立功能模块；不得从聊天内部导入统计、余额、配额、教程或生图业务实现。
兼容别名、HTML 解析回调和 Gunicorn 生命周期钩子仍有调用者，不能只凭直接引用数量删除。

## 身份与接口边界

- 所有路径先绑定服务端验证的稳定用户 ID。客户端不能通过用户名、KEY、UUID、目录或 `user_id` 字段指定另一个用户。
- 普通用户和管理员都只能访问自己的聊天、设置及文件；同用户不同聊天的模型文件工具也互相隔离。
- 聊天只接受本人登录会话及匹配的 `X-Cockpit-Session`；写操作还需要同源检查和 `X-Cockpit-Chat: 1`。管理员 PAT 不用于聊天接口。
- 新聊天可以没有 KEY 或附件。首次发送前自动建聊天；上传与引用附件不替代用户正文，也不要求先选模型。
- 历史列表包含未删除的空、失败和中断聊天，按游标分页；不能只列成功项或第一页。单次快照合并恢复所需的状态和增量。
- 写入使用规定的版本、确认和请求标识。版本冲突不得自动覆盖；同一已接受运行不得再次派发。具体请求字段和错误码由 `schemas.py`、`http.py` 及 `openapi.py` 维护，文档不另复制一套完整 schema。
- 付费 POST 不自动重试；刷新、SSE 重连和只读恢复不能启动模型、摘要或自动记忆调用。临时 429/503 不清空草稿、引用或当前聊天。

## 存储与提交

聊天使用单宿主机、本地 POSIX 文件系统；`./data/chat` 绑定到 chat 池，web/image 不挂载。禁止多主机共享 NAS/NFS、软链接逃逸或未挂载时回退容器临时层。

实例根目录绑定稳定的 `CHAT_INSTANCE_ID`，其下按用户 ID、聊天 ID 隔离。保存内容包括：

- 聊天元数据、顺序事件日志及 `commit.json` 提交高水位；
- 上传原件、生成文件版本和运行快照；
- 用户个人设置的 manifest、内容版本和运行时冻结副本；
- 上下文检查点、自动记忆意向/审计，以及附件删除控制记录；
- 可重建的列表、位置和用量索引。

写操作在跨进程锁、容量预留和有界持锁时间下执行。先写入并同步数据，再发布提交高水位；读取不能把高水位之后的尾部当作已提交结果。
恢复只接受可验证的已提交前缀；索引损坏可以重建，但不能静默跳过损坏事件、复活已删除内容或将未完成工具写入认作成功。
热读取使用有界投影与区块索引，不能承诺任意规模冷历史都是常数开销。

个人设置 manifest 是权威提交点，不是可随意删除的缓存；它与聊天事件不是同一个原子文件。
主机管理员和备份操作者仍可能读取明文；应用隔离不等于磁盘加密。

## 模型调用与流式处理

支持 Chat Completions、Responses 和 Anthropic Messages。协议层分别转换正文、工具结果、用量和原生状态，不能只换 URL 复用另一协议的消息结构。

- KEY 必须归当前用户所有，模型必须在本人实际授权目录内；不自动创建公共 KEY、改组或扩大额度。
- 当前页面没有普通聊天/Agent 模式选择，默认提供附件与可用工具，固定一个回答；历史多候选及兼容 API 仍可读取。
- 附件正文由服务器读取后加入当前请求，不以“未确认工具能力”禁用全部模型。实际协议或能力不匹配时明确报错，不偷偷换协议、渠道或模型再收费。
- SSE 需要处理任意分块、UTF-8 边界、结束标记、异常和取消；HTTP 200 本身不代表生成完整。公开正文、工具步骤及用量按已提交事件推送。
- 只展示上游实际公开返回的 reasoning/thinking 文本；签名、加密状态不是思考原文。原生连续状态只能在匹配的协议、模型、本人令牌及能力版本下重放。
- 流式文字与工具调用中断后不能伪造成成功；历史保留安全的部分内容，后续模型输入不得重放残缺的工具调用链。

本节的聊天运行预算与[鹈鹕测试](intelligence.md)不同：聊天整轮截止为 180 秒，主请求最多 6 次，辅助请求最多 4 次，总计最多 10 次；全部派发共用停止、时间、身份和存储预算。
其他限制以 `config.py` 为准，公网工具独有参数以 `web_tools.py` 为准，不能在协议适配器里新增隐藏重试或无限循环。

## 文件与公网工具

上传原件只读，输出生成新版本；单个附件最多 50 MiB，JSON、工具结果、输出文件和上下文仍分别受更小的限制，不随上传上限一并放大。
PDF、Word、Excel、图片由服务器有界解析；图片及扫描页按所选模型协议传入。PDF/DOCX/XLSX/PNG 等输出由实际渲染器生成并校验格式，不靠更改扩展名。
工具只能访问当前用户、当前聊天工作区，不接受任意宿主路径；不执行上传文件、模型代码、shell、浏览器或 Skill 脚本。

附件删除先发布持久删除标记，再移除原件；原件下载和引用随后拒绝，历史显示占位。上下文检查点不能跨删除继续复用原件，也不能通过恢复旧缓存绕过删除。
生成文件和原件的删除规则不同；不向模型提供删除原件的工具。细节见[附件删除与升级](chat.md#附件删除接口与升级)。

公网工具只允许无业务凭据、标准端口的公网 HTTP(S) 地址，不转发 Cookie、KEY 或认证头，不继承环境代理。
DNS 全部地址先检查再固定数值地址连接，TLS 仍校验原主机；重定向逐跳复查，拒绝内网、元数据地址、特殊地址、HTTPS 降级和绕过。
响应、地址数量、重定向、读取和总时间均有界；不承诺支持登录网站、反爬、压缩响应或任意字符编码。
搜索依赖运维配置的 SearXNG；未配置时不伪造搜索结果，也不因此禁用独立的公网读取。

## 个人设置与自动记忆

`MEMORY.md`、`SOUL.md`、`IDENTITY.md` 和文本 Skill 只属于本人。Skill 是提示模板，不是可安装执行的程序。
运行接受时在版本保护下冻结个人设置和已选 Skill；同一运行内不重读较新的设置，也不回写旧快照。已有聊天的载入状态与用户模板库分开管理。

自动 Memory 只提取当前聊天里用户明确表达的长期事实/偏好，不把网页、工具内容、附件指令或模型猜测提升为用户授权。
自动写入受结构、数量、大小、来源和版本校验约束；不改 SOUL/IDENTITY，发生并发编辑时不覆盖。
提交意向与个人设置 manifest、完成审计分开：只有已完成且可验证的审计支持一键撤销。崩溃留下的意向不等于确认成功，也不自动重放或再次收费。
撤销使用最新个人设置版本和聊天版本，不能拿历史运行的冻结版本覆盖现有设置。

## 工作上下文与历史

完整历史归档与发送给模型的工作窗口分开；压缩不删除历史，也不冒充原始用户文字。
尽量使用完整可重放对话，达到预算阈值后保留近期完整轮次、当前任务、个人设置、文件引用和工具配对，再处理较早前缀。

- 明确声明支持原生压缩的 Responses 渠道可以调用 `/responses/compact`；整个返回窗口必须按兼容绑定重放，不能只抽取某个加密字段。
- 其他已配置渠道使用受控的可读摘要。原生压缩失败后不偷偷切换方案并再收费。
- 检查点保存覆盖轮次、源哈希和兼容绑定；与附件删除、KEY/模型变化或源历史不匹配时不能复用。
- 待压缩投影的 `messages=None`，必须先完成压缩并重新核对预算才能派发主请求。运行内窗口与可跨轮复用的检查点不能混为一谈。
- 摘要和 Memory 是独立辅助用途，记录实际请求与实际返回用量；缺失用量不记成零。
- 放不下的必留内容、超长旧历史或超预算输出必须明确失败，不能静默截断，也不能无限收费压缩。

## 前端、验证与升级

浏览器只缓存账号关联的选择和安全摘要，不保存聊天正文、凭据或全文文件；账号切换立即隔离旧状态。
只读恢复采用有界增量和失败退避，保持阅读位置、展开项及文字选择，不通过重新生成补齐缺失结果。
当前输入区允许无附件发送；输出内容只列生成文件。移除的上下文/Skills/只读刷新按钮不再由旧设计稿恢复。

修改上述边界时运行[离线回归](../CONTRIBUTING.md#ai-助手离线回归)，必要时使用独立 PostgreSQL/Redis 和本地合成上游；不得拿生产凭据或付费模型消除测试跳过。
备份与降级见[升级手册](upgrading.md)：先停止聊天写入，保留完整数据及稳定实例 ID。旧版本不一定理解新事件和删除标记，禁止仅换旧镜像继续写新数据，或覆盖新活动以“回滚”。
