本轮在 `develop` 实施。Cockpit 版本为 **0.4.1**，随附的 VS Code 插件独立编号为 **0.4.2**。发布、镜像和部署状态以对应 GitHub Release 及实际运行版本为准，不把本地检查称为生产验收。

| 项目 | 实施内容 | 验收边界 |
|---|---|---|
| 管理员 PAT 校验与权限 | 由 New API 验证有效性，再以源库哈希字段收窄权限 | 不通过明文匹配绕过上游撤销、到期及权限检查；保留网页登录 |
| 临时鉴权故障保留草稿 | 区分认证失效与上游故障、限流 | 503/429 不清空正文、引用或当前聊天，不自动重发 |
| 插件独立使用 | 余额直接读取 New API `/api/user/self` | 不需要 Cockpit 或 MCP；首次及每小时按需读取公开额度单位，不猜测单位 |
| 插件 KEY 操作结果核对 | 新建及跨页修改/删除丢失回执后在插件内核对 | 不重发写操作，不跳网页，不增加二次核对或手动查询冷却 |

| 令牌及模型目录请求合并 | 普通目录冷缓存最多 4 次、热缓存最多 2 次上游请求 | 不含会话和路由检查；不同 KEY 不互相阻塞；不缓存授权 |
| 聊天恢复查询合并 | 单次快照返回必要状态和增量，失败退避 | 遵守上游等待时间，只读恢复不续跑模型 |
| 聊天存储增量化 | 增量追加、有界位置索引与按区块校验翻页 | 热缓存无增量不重放完整历史；旧数据、删除、崩溃恢复兼容 |
| 聊天页面增量渲染 | 只更新变化消息 | 保留阅读位置、展开项及流式文字选择 |
| 静态缓存与连接复用 | 公共资源重验证、有界身份隔离连接池 | 私人响应仍不缓存；无自动重试；模型生成不纳入目录连接池 |
| 自动记忆调用优化 | 精确无事实短回复跳过无收益检查 | 默认全能力不变；明确要求记住的信息不遗漏 |
| 兼容入口与文档清理 | 保留有调用者的轻量别名，删除未采用的 New API 补丁方案 | 不维护第二份业务实现，不给不同 SQL 统计口径强行套同一构造器 |

## 不变的规则

- 不修改 New API 镜像，不构建、分发或安装上游补丁。
- 不更改计费日志、金额或余额统计口径，不自动重发有副作用或收费的请求。
- KEY 管理保留手动查询，以及每次修改前、后的实时查询；不加插件冷却或网页核对。
- 认证与权限不跨请求缓存；同一请求内可以复用已经验证的数据。
- 不把密钥、密码、私有站点清单写入源码、日志或公开文档。
- 存储优化不能复活已删除附件，不能让不兼容旧版本继续写入新事件。

## KEY 改组与配置编辑

插件和 Cockpit 服务端均沿用官方 **`PUT /api/token/`**，不是自定义 PATCH。操作前读取最新配置，修改目标字段并保留其他设置。已撤回未发布的 PATCH 接口依赖和相关 New API 补丁；其余请求合并、结果核对与存储优化保留。

官方 PUT 会完整写入 KEY 的剩余额度，因此不能保证与并发消费原子执行。普通改组可以正常使用，但不能把“查最新值再保存”宣传为已彻底解决额度并发覆盖。这里涉及 KEY 自己的调用限额，不是直接修改用户账户余额。行为依据见[官方控制器](https://github.com/QuantumNous/new-api/blob/34003e9c2eed2c20e617f583fdfe54bf1bf42237/controller/token.go#L426-L451)。

跨用户管理继续取得并使用所属用户 PAT；没有改成不存在的管理员跨用户 KEY 接口，也没有修改 PAT 获取、撤销或上游退役设置。

## 验证范围

- Python 使用禁止外部网络和未模拟数据库连接的源码回归；因可选数据库条件跳过的项目不计为通过。
- 插件使用本机虚构 New API HTTP 服务，覆盖独立余额查询、单位缓存、金额精度、认证错误、429、连接池、KEY 操作顺序与丢失回执；不依赖 Cockpit 进程。
- 插件改组校验完整 PUT 的未修改字段，余额定时更新不读取 KEY，普通操作不增加同一 KEY 的额外详情查询。
- 聊天存储覆盖真实临时文件、跨进程锁、中断恢复、附件删除、拒绝写入后投影不变、位置索引、篡改拒绝、描述符释放和损坏日志有效前缀兼容。
- 聊天页面已有 112 项单元/控制器回归和 39 项完全拦截请求的本地浏览器回归；覆盖恢复请求数、退避和文字选区保留。性能测量与局限见[性能机制](performance.md)。
- 实际 Dockerfile 构建检查由发布 CI 执行：运行镜像以 UID 10001 启动，不带 Node 或私有配置；核对随附 VSIX 身份、版本、摘要、下载鉴权及 `no-store`。应用和插件不要求同号。
- Linux 文件语义检查修正了测试的 `O_APPEND` / `pwrite` 组合，先证明确实原位篡改，再验证读取拒绝。

## 已完成的隔离运行验证（2026-10-26）

经确认在 token-factory 主机创建独立临时实例，不读取站点数据库或私有环境文件，不对外发布端口，也不替换现用服务。

- PostgreSQL 16：新建无网络实例，只有虚构源表与测试角色。实际执行 PAT 函数和 `source-grants.sql`，4 项通过；验证列级读取、写入拒绝、哈希/归属/到期限制、旧表结构与重复授权。上游身份接口使用模拟返回，不是线上登录验收。
- Redis 7：缓存、回执私有目录及回执命名卷均以 `999:1000` 运行；重启和重建后 AOF 保留。两种回执服务通过实际 `claim` / `finish` 后的重建去重检查，不调用模型。
- 临时容器、卷和上传目录均已清理，现用容器的 ID、启动时间、重启次数及状态未变。
