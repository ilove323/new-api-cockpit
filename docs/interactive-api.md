# 交互式 API 文档

管理员登录后，从侧边栏打开“API 文档”：`/cockpit/docs/`。
页面使用本站真实接口，不是沙箱。打开页面只读取接口描述，不查询用户或用量，不发送通知。

## 第一次调用

1. 点击“查看账本”，核对接口后点“发送请求”，从响应取得账本 ID。
2. 点击“查询余额”，填写 `scope_id`；不填时查询全部账本。
3. 调试身份改为“管理员 PAT”，填入 New API 管理员的 PAT 原值，然后发送。
4. 在实际响应中查看状态码和余额；复制 curl、Python 或 JavaScript 示例接入自己的程序。

PAT 不是模型调用 KEY，不添加 `sk-` 前缀。页面默认用当前登录会话调试，余额和报警只接受 PAT。
输入 PAT 后，请求以该 PAT 的管理员身份执行，不以当前网页登录身份执行。
程序示例使用环境变量 `ADMIN_PAT`，不会带上输入的 PAT。
HTTP 401/403 时检查凭据和权限；409 时重新核对版本或预览，不直接重发。

## 常用流程

- **用户额度**：查用户 → 修改预览请求中的用户 ID、每人金额和增减方式 → 发送预览 → 核对前后额度 → 确认执行。
  在线调试要求本页已成功预览完全一致的请求；改变身份或参数后需重新预览。
  执行一旦发起就消耗本页预览，失败或断连也不能直接重复执行。
- **KEY 改组**：查 KEY → 填目标组和 KEY ID → 预览冻结名单 → 核对名单 → 执行下一组。
  每次最多 5 个；只有上一组完整返回且全部成功、还有剩余时才能手动继续。
  改配置前先暂停 KEY 并发调用，不把 KEY 限额当用户充值。
- **余额报警**：查询余额不发通知。“检查报警”会实际检查并可能发送，单独确认后执行；重复调用可能重复发通知。
- **渠道质量**：在接口下拉框选择质量汇总，填写时间、模型或渠道；只读查询不发送通知，也不改变路由。
- **智力测试**：先查可测试模型，再选择测试接口填写模型名。发送测试会复用或创建专用 KEY 并实际扣费；核对确认后只发一次。
  调试器显示返回的 HTML 源码，内嵌动画请到“智力测试”页面查看。

点击流程按钮只填写编辑器，不发送请求。示例 ID、金额、版本号必须换成自己核对的实际值。
完整业务接口都可在下拉框选择，自动填写接口要求的确认头；这些头不是幂等键。
浏览器会话承接和清除接口只供参考，调试器不执行，登录/退出使用正常入口。

## 接口参考与安全

“完整接口参考”按模块展示参数、请求/响应结构和错误，支持搜索。
参考区使用本地打包的 Scalar；实际调试集中在同一编辑器，统一检查目标地址、预览和确认。
版本、限额、各操作参数的详细解释见 [API 参考](api.md)。

- 所有调试请求只发往当前协议、域名和端口，不使用外部代理。
- 修改、通知、可能补建 PAT 的详情读取、查看 KEY 明文都会要求确认，不能只按 GET/POST 判断风险。
- 只发一次，不自动重试，不自动执行下一组。HTTP 200 也要检查逐项结果；断连或超时先查实际数据和操作记录。
- PAT 不写 localStorage/sessionStorage、URL 或日志；离开页面时清除。请求体、响应和导出文件只留在页面内存。
- 认证、权限和审计仍由业务接口执行。前端确认仅防误操作，不提升权限。

## 维护

OpenAPI 描述为 `/cockpit/api/openapi.json`，需要管理员会话或 PAT。
`openapi.py` 显式定义参数、结构、例子及调试元数据；路由覆盖测试检查漏写接口。
每个应用进程复用一份不含业务数据的 JSON 描述，但每次访问仍校验管理员身份。
增加接口时同步更新这份契约和 [API 参考](api.md)，不在文档页另写业务逻辑。

Scalar 1.73.1 的独立浏览器包随应用分发，按需加载，无运行时 CDN、字体服务、遥测或第三方请求代理。
许可见 [SCALAR-LICENSE](../src/new_api_cockpit/static/SCALAR-LICENSE)。更新依赖时固定版本，从官方 npm 包取 `dist/browser/standalone.js`，
同步许可证与 NOTICE；不拷贝源码映射或整套开发依赖。
文档页单独允许 Scalar 注入样式，其他页面的 CSP 不变；脚本和网络请求仍限本站。
文档页本身不需要数据库结构；写操作和模型测试所需的审计仍使用现有监控库，按[升级说明](upgrading.md)初始化和迁移。
完整转发 `/cockpit/` 的 Nginx 配置不需要为文档页新增规则。
