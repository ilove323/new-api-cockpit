# 智力测试

所有启用用户登录后均可从侧边栏进入 `/cockpit/intelligence/`，选择模型后点击“开始测试”。目前只有**鹈鹕骑车测试**，固定题目：

> Generate an SVG of a pelican riding a bicycle

使用 [Simon Willison 公布的原始题目](https://simonwillison.net/2024/Oct/25/pelicans-on-a-bicycle/)，所有模型只收到这一条用户消息，不附加系统提示词。
原题要求 SVG 图画，不要求动画或 HTML。完整 SVG 会在本地套上用于沙箱显示的 HTML 外壳，不修改图形；源码保留模型实际输出，包括可能存在的代码围栏。模型返回完整 HTML 内嵌 SVG 时也可以预览。
回答在代码块前后附带说明文字时，可以从单个完整的 SVG/XML/HTML Markdown 代码块提取预览；说明文字和代码围栏仍完整保留在源码中。不补全缺失标签或代码围栏，也不自动选择多个候选代码块。
页面流式显示生成状态和收到的源码，没有后台任务、进度轮询、历史列表或结果数据库。
生成完成后内嵌显示图画，可切换源码、重新播放和全屏。重新播放只重新载入当前预览，不再调用模型、不增加费用。
刷新、离开页面会清空结果，之后不能按 ID 找回。模型调用正常计费，刷新不保证撤销已经发出的调用。
Cockpit 不保存结果；New API 仍可能按其配置记录用量、请求或上游日志。

## 模型与分组

管理员读取官方 `/api/models/` 管理目录，包含已有渠道的模型，最多 2000 条目录记录；分页异常不返回部分列表。普通用户使用本人登录会话读取 `/api/user/models`，最多 10000 个模型名，不调用管理员目录。
两者均与当前启用渠道和本人可用分组取交集，不依赖公开价格页开关，不修改 New API 导航设置。管理员目录的文本能力声明用于排除纯图片、音频模型；普通用户接口只有模型名，不凭空补协议声明。
测试协议按优先渠道类型决定：

| 渠道类型 | 测试协议 | 路径 |
|---|---|---|
| Anthropic（类型 14） | Claude Messages | `/v1/messages` |
| 其他 | OpenAI Chat Completions | `/v1/chat/completions` |

不根据模型名是否含 `claude` 判断，也不取目录中排在第一位的端点。
选组优先当前用户自己的用户组，否则按组名排序，页面显示自动选中的分组。
同一分组下有多个可用渠道时，按渠道优先级从高到低选择，优先级相同则选 ID 较小的渠道。
管理员生成使用 New API 的指定渠道机制，把协议和该渠道绑定。普通用户没有指定渠道权限，使用不带渠道后缀的本人 KEY，由 New API 在所选分组内正常路由；目录渠道只作为测试协议选择依据，返回结果不冒充已固定实际渠道。
开始测试时重新检查，不使用已经失效的页面目录。不会修改用户组或扩大分组权限。
生成前再以测试 KEY 查询 `/v1/models`，核对该模型当前可用，包括计费配置与令牌限制。
选中的渠道不能接受对应协议时直接报错，不自动换渠道或换协议再发一次收费请求。

## 专用 KEY

固定名称为 **`cockpit-智力测试专用`**，所属用户取当前登录用户，外部 PAT 调用则取该 PAT 对应的管理员。
按用户 ID 和名称精确查找，只用未删除的 KEY。不存在才创建；存在多个同名 KEY 时要求在 New API 令牌页面保留一个。
KEY 一直保留，测试结束不删除。首次创建永久有效、无限 KEY 额度，实际仍从当前用户账户余额扣费，不给账户充值。
已有 KEY 的额度、有效期、启禁状态和 IP 限制不自动重置；已禁用、过期或额度耗尽时，到 New API 令牌页面调整后再测。

每次生成前把专用 KEY 设置为所选分组，只允许所选模型，关闭跨组重试。
管理员创建与配置通过本人 PAT 调官方令牌接口，缺少 PAT 时复用现有受限补建函数。普通用户直接使用自己的已验证登录会话调用官方令牌接口，归属由后端与 New API 双重核对；不读取或补建普通用户 PAT，不借用管理员凭据。
源数据库仅查询，除了已有 PAT 补建函数外不直接写入；不新增源库函数、权限或表。
KEY 创建、配置沿用现有操作审计，完整 KEY、PAT 和生成内容不进入操作记录。
凭据只在后端当前请求内使用，不返回浏览器。
官方返回的原始 KEY 可以不带 `sk-`，后端统一补齐；已有前缀不重复添加。
管理员指定渠道只追加到本次请求的认证凭据，不修改数据库中保存的 KEY。

## 流式生成与边界

同一用户的测试用监控库 session advisory lock 串行保护，第二个并发请求返回 409，不排队执行。
锁覆盖 KEY 查找、创建、配置与模型调用，连接关闭即释放，不新增任务表或锁表。
需要已有监控库保存 KEY 操作审计；这不表示保存测试结果。

生成请求使用 `stream: true`，从调用模型开始最多 **300 秒（5 分钟）**，包括连接、等待、思考及输出读取；持续收到数据也不会重置这个总时限。前面的模型核验和 KEY 准备不计入生成时限。
页面依次显示校验模型、准备 KEY、等待响应、思考（上游有对应事件时）和生成 SVG；收到文本后显示字符数及实时源码。用时由当前页面计时，不是进度百分比，也不会为了刷新状态额外请求 New API。
OpenAI Chat Completions 和 Claude Messages 均支持流式文本。思考内容只用于标识“正在思考”，不会送入源码、预览或结果。
只有收到协议完成标记并通过 SVG/HTML 完整性检查，才启用预览。超时、流中错误或断线时，页面保留已经收到的源码，但不把它当作完成结果，也不会自动重试。
如上游忽略流式参数而返回 JSON，消费这一份响应后返回结果，不再补发第二次调用。
Cockpit 不设置 `max_tokens`、`max_completion_tokens` 或 `max_output_tokens`，输出 Token 上限由 New API 和上游决定。
Claude 协议要求的 `max_tokens` 由 New API 按模型配置补齐；实际输出仍受 New API、渠道和模型自身限制，不表示模型能无限输出。
Claude 渠道应使用 New API 的常规转发；开启请求体透传会跳过这一步，需由上游提供默认参数。
接口原始响应最多 2 MiB（包括 SSE 帧和思考数据），这是响应体保护，不是模型生成 Token 配额。
流式响应需要 OpenAI 的结束原因及 `[DONE]`，或 Claude 的结束原因及 `message_stop`；缺少完成标记即使 HTTP 为 200，也不当作成功。
可预览 HTML / 显示源码最多 512 KiB；截断、拒答、内容过大或缺少完整 SVG 时不自动修复，页面显示提示及可用源码。
只验证能否提取完整 SVG 或包含 SVG 的 HTML，不自动判定画得好不好，不生成“智力分数”。
超时、断线或错误响应不自动重试，已有消费以 New API 日志为准。
上游截断、上下文耗尽、拒答或内容拦截时，提示显示实际结束原因，并保留可用源码。
模型生成占用一个 Web 请求线程；不要同时压测大量账号。应用没有新增线程池、队列、后台执行器或独立容器。
网页请求携带 `Accept: text/event-stream`，通过同一个 POST 响应接收 `status`、`text`、`heartbeat`、`result` 或 `error` 事件，不使用会自动重连的 EventSource。
没有请求 SSE 的 API 客户端仍收到一次性 JSON；两种返回方式共用同一次流式模型调用。响应头发出前的输入/并发错误返回正常 HTTP 错误码；发出后发生的错误通过 `error` 事件携带 `status` 和 `uncertain`，不能只看 HTTP 200。
Nginx 示例仅将 `/cockpit/api/intelligence/test` 的读取超时放宽到 360 秒，并关闭该 location 的缓冲、缓存和 gzip；其他接口保持原有配置。应用也返回 `X-Accel-Buffering: no`。
浏览器外层等待上限为 420 秒，为 KEY 准备、网络及结束事件留余量，不代表模型可以生成 7 分钟。模型仍受后端 300 秒硬截止约束。
预览接口单独允许 2 MiB 请求体，覆盖 HTML 表单编码后的体积；实际 HTML 仍限制为 512 KiB。
停机或部署时不接续尚未返回的测试。
请求结束或断连被服务器感知后关闭上游连接并释放锁；不能保证已经发送到上游的工作立即停止或不计费。

## HTML 预览

生成内容不插入管理页面的 DOM，也不由后端执行。
浏览器把当前内存中的 HTML 用同源 POST 表单提交到 `/cockpit/api/intelligence/preview`，返回独立预览响应。
表单需要匹配当前登录会话；外部 API 可使用管理员 PAT、JSON 和 `X-Intelligence-Request: 1`。
生成等待较长时，预览前刷新原登录会话；账号已切换就停止预览，不重发模型请求。
HTML 不放在 URL，不生成临时文件或服务端结果缓存。
预览与重播不依赖浏览器的 `crypto.randomUUID()`；窗口名称使用页面内递增序号，不作为身份凭据或模型请求 ID。

预览使用独立桌面尺寸画布，按当前窗口等比例缩放。
预览窗口高度随屏幕调整，也可拖动右下角调整高度；全屏时重新适配。
沙箱内的尺寸测量脚本只回传宽高，管理页面只接受当前 iframe 的尺寸消息，并限制尺寸及调整次数。
内容超出初始画布时扩展画布再缩放，避免居中布局把标题、底部裁掉；源码仍是模型原始输出，尺寸脚本只加入预览响应。
尺寸脚本是随包分发的固定资源，由应用进程复用；HTML 每次从当前请求读取，不缓存生成结果。

iframe 只允许脚本，不允许 `allow-same-origin`；响应本身也有 HTTP CSP sandbox，直接打开响应仍受限制。
内联 SVG/CSS/JavaScript 可运行，外部脚本、网络连接、嵌套页面、表单、弹窗和顶层跳转受限。
预览不读取管理页面、Cookie 或本地存储；只有预览响应允许内联脚本，管理页面保持 `script-src 'self'`。
沙箱不保证生成代码没有性能问题；大量动画或死循环仍可能影响浏览器，可离开页面停止查看。

接口格式见 [API 参考](api.md#智力测试接口)。
