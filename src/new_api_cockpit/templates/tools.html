常见问题

模型 KEY 能用，MCP 或插件却报 401 / 403

模型 KEY 和用户 API PAT 不能互换。401 检查 PAT 是否有效、已过期或被撤销；403 按当前功能补齐权限。插件配置连接时填写用户 PAT，生成 Claude / Codex 配置时才使用选中的模型 KEY。

余额和 KEY 列表为什么没有一起刷新？

余额默认每 15 分钟刷新，手动刷新至少间隔 60 秒；429 会按服务器要求延后。KEY 列表没有自动刷新和查询间隔，点 KEY 区刷新才重新读取，新建、删除、改分组前后各查询一次。两套刷新规则独立。

遇到 429 或连接断开怎么办？

429 是服务端限流，插件不自动重试。ECONNRESET 表示连接中断，不等于证书失效；检查 VS Code 的代理和网络。只有明确的证书校验错误才检查证书有效期、域名和证书链，不要关闭 HTTPS 校验。

草稿怎样保存？为什么还没有生效？

在草稿编辑器中按 Ctrl+S（macOS 为 ⌘S），或点击草稿上方、编辑器右上角的保存按钮。Codex 的 config.toml 和 auth.json 都要保存，再重载 Codex。自动保存不会写入原配置；原生“另存为”会使用你自行选择的路径。

远程 SSH、容器或 WSL 窗口能配置客户端吗？

余额和 KEY 管理可以使用。客户端配置草稿目前只支持本机窗口；不会用本机目录代替远程目录。Windows 下让 Codex 在 WSL 运行时，也不会修改 Windows 主目录中的同名配置。

MCP 示例的复制按钮不可用

通过 HTTPS 或本机安全地址打开页面，并允许浏览器访问剪贴板。也可以手动复制示例；其中的 USER_API_TOKEN 仍需在客户端替换成自己的用户 API PAT。
